# Правила общения

Здесь общаются стримеры, зрители и разработчик EVO VOICE. Правила простые: уважайте друг друга.

## Можно и нужно

- Писать по делу: ошибки, идеи, вопросы по программе.
- Спорить об идеях, а не о людях.
- Помогать новичкам и отвечать вежливо, даже если вопрос уже задавали.

## Нельзя

- Оскорбления, угрозы, травля, унижение по любому признаку: полу, возрасту, национальности, вере, внешности,
  ориентации, здоровью.
- Спам, реклама, ссылки на сторонние сборки и «взломанные» версии программы.
- Публикация чужих личных данных: имён, адресов, переписки, логинов.
- Записи и голоса реальных людей без их согласия, в том числе в примерах к обращениям.

## Что будет при нарушении

Разработчик может отредактировать или удалить сообщение, закрыть обращение, временно или навсегда запретить писать в
репозиторий. Решение принимается по ситуации; при серьёзном нарушении — без предупреждения.

## Как пожаловаться

Нажмите «…» у сообщения → **Report content** или напишите через раздел «Связь» в программе. Жалобы рассматриваются
конфиденциально.

Правила действуют в обращениях, обсуждениях и pull request этого репозитория, а также в каталоге голосов программы.
