# EVO VOICE

Озвучка Twitch-чата голосами нейросетей. Программа для Windows (64-бит).

**Скачать:** [последний выпуск](https://github.com/RASTUf/evo-voice-releases/releases/latest) → файл `EVO-VOICE-Setup-<версия>.exe`.

## Что умеет

- Читает чат вашего Twitch-канала и озвучивает сообщения выбранным голосом.
- «Разные голоса»: каждому зрителю свой голос.
- Библиотека голосов и несколько моделей озвучки на выбор (Supertonic, Qwen3, Chatterbox, ESpeech, XTTS). Озвучка
  работает **на вашем компьютере**, текст сообщений никуда не отправляется.
- «Создать голос»: свой голос из записи или файла.
- «Пользовательские голоса»: каталог голосов, которые выложили другие пользователи.
- «Клипы»: находит яркие моменты в записи стрима и нарезает вертикальные клипы с субтитрами. Тоже на вашем компьютере.

## Безопасность

Мы понимаем, что незнакомая программа вызывает вопросы. Поэтому подробно описали, что она делает, куда
обращается и что хранит: **[Безопасность и приватность](SECURITY.md)**.

Коротко:

- Программа **не просит пароль от Twitch**. Вход идёт через официальную страницу Twitch по коду (twitch.tv/activate).
- Не нужны права администратора: программа ставится в папку пользователя.
- Не запускается сама вместе с Windows.
- Не читает браузеры, сохранённые пароли, кошельки и личные файлы.
- Обновления подписаны: программа не поставит файл, если подпись или контрольная сумма не сошлись.

## Почему Windows предупреждает при установке

Установщик пока **не подписан сертификатом разработчика**. Поэтому Windows SmartScreen может показать окно
«Windows защитила ваш компьютер» и «Неизвестный издатель». Это предупреждение о том, что у файла нет подписи, а не о том,
что в нём найден вирус. Чтобы установить: «Подробнее» → «Выполнить в любом случае».

Перед установкой можно убедиться, что файл именно наш и не изменён. Контрольная сумма SHA-256 указана в описании каждого
выпуска. Проверить её можно в PowerShell:

```powershell
Get-FileHash "$env:USERPROFILE\Downloads\EVO-VOICE-Setup-1.0.4.exe" -Algorithm SHA256
```

Если число совпало с указанным в выпуске, файл тот самый.

Качайте программу **только отсюда**. Если кто-то присылает «EVO VOICE» с другого сайта или в личных сообщениях, не
запускайте этот файл.

## Удаление

«Параметры Windows» → «Приложения» → EVO VOICE → «Удалить». Настройки и голоса лежат в папках, перечисленных в
[SECURITY.md](SECURITY.md#что-хранится-на-компьютере); их можно удалить вручную.
